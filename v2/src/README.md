# Исходники v2

Тексты лежат в `ru.json`, `uk.json`, `en.json`, `es.json`, `pl.json`, разметка — в `template.html`.
После правки пересоберите страницу (номер — версия для сброса кэша браузеров):

    node build.js 2

Сборщик заново создаёт `../index.html` и `../js/i18n.js`. Стили и скрипты (`../css/style.css`, `../js/main.js`) правятся напрямую.
